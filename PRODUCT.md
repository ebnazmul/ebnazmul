# Product

## Register

brand

## Users

Potential collaborators, employers, and other developers visiting Nazmul's GitHub profile or personal site.

## Product Purpose

Present Nazmul's current professional direction clearly and provide direct paths to email and GitHub without inventing work history or credentials.

## Brand Personality

Curious, technical, and direct. The site should feel like a carefully built instrument rather than a generic portfolio template.

## Anti-references

Avoid generic developer dashboards, fake terminal interfaces, repeated card grids, inflated claims, and fabricated project case studies.

## Design Principles

- Make the current direction immediately understandable.
- Demonstrate frontend judgment through the interface itself.
- Keep claims specific and honest.
- Make contact and source code easy to reach.
- Respect motion and accessibility preferences.

## Accessibility & Inclusion

Target WCAG AA contrast, semantic HTML, keyboard-visible interactive states, responsive layouts, and reduced-motion support.
