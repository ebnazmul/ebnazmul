# Design System

## Theme

A near-black technical canvas with a committed green signal color. The visual reference is a precision instrument display viewed in a dim workspace, not a decorative terminal.

## Color Palette

- Background: `oklch(0.08 0 0)`
- Surface: `oklch(0.14 0.012 160)`
- Primary: `oklch(0.68 0.17 158)`
- Primary bright: `oklch(0.84 0.19 158)`
- Secondary: `oklch(0.78 0.16 75)`
- Text: `oklch(0.96 0 0)`
- Muted: `oklch(0.72 0.01 160)`

## Typography

- Arial/Helvetica for readable interface and display text.
- Courier New only for short technical signals and the wordmark.
- Large headings use tight spacing, balanced wrapping, and a maximum size of 96px.

## Layout

- Mobile-first responsive layout.
- Fluid page gutters and section spacing.
- Hero uses an asymmetric copy and signal composition.
- Focus areas use a ruled list rather than repeated cards.

## Components

- Text navigation with visible focus behavior.
- Filled primary action and understated text action.
- Animated signal graphic built with CSS, with reduced-motion fallback.
- High-contrast contact footer.
